BREAK100 v1.42 — START HERE
===========================
Observe / Shadow. Real synthetic account is OK for tick data.
This EA does NOT send broker orders.

Grok Build (this chat) does not install on your laptop and cannot
remote it. Put the project on the laptop like this.

------------------------------------------------
Windows PowerShell  (does copy + compile)
------------------------------------------------
1. Unzip BREAK100-MT5.zip. Keep the folder together.
2. Desktop MT5 must already be installed and logged in (not the iPhone app).
3. Right-click Install-BREAK100.ps1 -> Run with PowerShell
   or paste:

     Set-ExecutionPolicy -Scope Process Bypass
     cd $HOME\Downloads\BREAK100-MT5   # or wherever you unzipped
     .\Install-BREAK100.ps1

4. If Windows blocks it:  Unblock-File .\Install-BREAK100.ps1
5. When it prints "Compile OK":
     MT5 Navigator -> Experts -> Refresh
     Drag BREAK100 onto Boom 100 M1
     AutoTrading OFF

That script finds every MT5 data folder, copies the files, and calls
metaeditor64.exe /compile (same as F7). You only attach.

Git clone of the same sources:
  git clone https://github.com/firyomaefx/synthetic-indices.git

------------------------------------------------
If the script cannot find MetaEditor
------------------------------------------------
Files are still copied. Then F4 -> F7 on BREAK100_Channel, then BREAK100.
Version in the file must be 1.42.
