# Work Breakdown Structure

1. Initiation (G0)
   1. Repository and capability audit
   2. Order-path and security audit
   3. Charter, scope, stakeholders, RAID baseline
2. Planning (G1)
   1. Architecture and data contracts
   2. Feature, label, model, and cost specifications
   3. State machine, execution isolation, risk and test design
   4. Requirements traceability and sequenced plan
3. Build (G2)
   1. Python data/event/research stack
   2. Statistical and ML pipelines
   3. Registry, ONNX export, parity and rollback
   4. Shadow simulator, ledger, risk and audit services
   5. MQL5 indicator and EA adapters
4. Validation (G3)
   1. Leakage-safe walk-forward analysis
   2. Cost, stress, bootstrap, calibration, and parity tests
   3. Deterministic replay and failure injection
5. Demo readiness (G4)
   1. Demo-only adapter and account verification
   2. OrderCheck, reconciliation, dashboard, runbook
   3. Shadow-versus-Demo calibration
6. Live Canary readiness (G5)
   1. Owner identity, allowlists, lease, canary caps
   2. Emergency stop, rollback, expiry and revocation
7. Closing and handover (G6)
   1. Final evidence, limitations, operations and release manifest
